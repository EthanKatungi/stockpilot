# StockPilot development guidance

Read [docs/designs/DESIGN_SOURCE_OF_TRUTH.md](docs/designs/DESIGN_SOURCE_OF_TRUTH.md) before UI work. The consolidated HTML design is the reference for new screens; approved Flutter screens take priority for their established appearance and behavior. Implement one phase at a time, validate it, and wait for user review before continuing. Do not use Figma MCP unless the user explicitly requests it.
