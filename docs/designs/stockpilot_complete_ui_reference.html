Implementation notes for Codex

Preferred usage: Save this document in docs/designs/stockpilot_complete_ui_reference.html inside the Flutter repo. Ask Codex to inspect screen IDs and their visual hierarchy, then implement each phase using native Flutter widgets and the existing app's design tokens.

UI only: All mock products, quantities, suppliers, names, emails, currency values and dates are fictional examples. Forms and buttons are illustrations, not functional persistence. Use the approved screen designs as the frontend contract; implement validation, data flow, database, permissions and transaction logic in later approved phases.

Color tokens: primary #14532D, accent #16A34A, mint #EAF5ED, background #F7FAF7, ink #17251D, muted #657469, border #E5ECE6. Reference width 393px. Use Material 3 and accessible responsive layouts.

Figma: StockPilot editable source file. The file remains the primary reference for any discrepancies.
